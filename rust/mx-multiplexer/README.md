# mx-multiplexer

The Rust client library of the
[multiplexer](https://github.com/kulewski/multiplexer), a message broker
for services on a trusted network: peers connect to several multiplexers
at once, register with a type, and exchange requests and events routed by
type according to a rules file, round robin across a pool of backends, to
every subscriber, or to one instance. Several multiplexers run
active-active, so there is no single point of failure.

The crate has the classes of the C++ and Python libraries, with their
names and their behaviour, and talks to their peers:

- `SyncClient`, for a program on one thread: every call runs the
  connections inside it.
- `ThreadedClient`, with an io thread of its own, for any number of
  threads; each of its waiting calls ends in `.wait()`, a callback, or
  `.await` on any executor, tokio's included, with no runtime of its own.
- `BaseMultiplexerServer` and `BaseThreadedMultiplexerServer`, the server
  classes a backend is built on: your `Handler` answers the requests, on
  the loop's thread or on workers.

```rust
use mx_multiplexer::SyncClient;

let mut client = SyncClient::builder(peers::ECHO_CLIENT).connect(["10.0.0.1:1980", "10.0.0.2:1980"])?;
let reply = client.query(types::ECHO_REQUEST, "hello").wait()?;
```

```rust
use mx_multiplexer::{BaseMultiplexerServer, Handler, HandlerResult, Request};
use std::time::Duration;

struct Echo;

impl Handler for Echo {
    fn handle_message(&self, request: Request) -> HandlerResult {
        request.reply(types::ECHO_RESPONSE, request.payload().to_ascii_uppercase())?;
        Ok(())
    }
}

BaseMultiplexerServer::builder(peers::ECHO_BACKEND, ["10.0.0.1:1980"])
    .build(Echo)?
    .serve_forever(Duration::from_secs(1), None)?;
```

`peers` and `types` are your rules file's, generated by `mxcontrol
generate_constants your.rules --rust src/multiplexer_constants.rs`;
`mxcontrol` is the multiplexer's command, from `pip install
mx-multiplexer`, the Debian package or the binary of every
[release](https://github.com/kulewski/multiplexer/releases). The crate
runs on Linux, with Rust 1.85 or newer, and depends on mio, prost, bytes,
libc and log.

[Using the Rust library](https://github.com/kulewski/multiplexer/blob/main/docs/api_rust.md)
describes every call;
[the overview](https://github.com/kulewski/multiplexer/blob/main/docs/README.md)
explains the protocol and its vocabulary.
